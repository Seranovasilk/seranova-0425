# Seranova Silk — Design Direction

## Brand
- **Name:** Seranova Silk
- **Tagline:** Sleep in Luxury, Wake in Silk
- **Tone:** Refined, elegant, sensuous, minimal

## Color Palette
- **Primary Background:** `#FAF7F2` (warm ivory)
- **Gold Accent:** `#C9A84C`
- **Gold Light:** `#E8D5A3`
- **Dark Text:** `#1A1208`
- **Muted Text:** `#6B5B3E`
- **White:** `#FFFFFF`
- **Warm Gray:** `#EDE8DF`

## Typography
- **Display Font:** Cormorant Garamond (serif, elegant, luxurious)
- **Body Font:** Poppins (clean, readable)
- **Heading sizes:** Large, generous line height
- **Body text:** 16px, 1.7 line height

## Layout
- Full-width hero with overlay text
- Asymmetric product grid
- Wide breathing sections with generous padding
- Gold dividers / accents
- Clean, minimal navigation

## Aesthetic
- Inspired by high-end fashion e-commerce
- Ivory base with gold touches
- Silk texture photography
- NO heavy gradients or purple tones
- Motion: subtle fade-in reveals on scroll
